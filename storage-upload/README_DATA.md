# ERA5-Minimum — данные

## Источник

Copernicus Climate Data Store.

Набор:

ERA5 hourly data on single levels from 1940 to present.

## Тестовая выгрузка

Дата: 2024-01-01.

Временные точки:

- 00:00
- 06:00
- 12:00
- 18:00

Пространственная сетка:

- latitude: 90.0 → -90.0
- longitude: 0.0 → 359.75
- разрешение: 0.25°
- размер: 721 × 1440

## Мгновенные поля

Файл:

`data_stream-oper_stepType-instant.nc`

Переменные:

- `u10` — восточная компонента ветра на высоте 10 м, м/с
- `v10` — северная компонента ветра на высоте 10 м, м/с
- `t2m` — температура воздуха на высоте 2 м, K
- `msl` — давление на уровне моря, Pa
- `sst` — температура поверхности моря, K
- `tcc` — общая облачность, 0–1
- `tcwv` — полное содержание водяного пара, кг/м²

## Накопленные поля

Файл:

`data_stream-oper_stepType-accum.nc`

Переменная:

- `tp` — total precipitation, м
- GRIB step type: `accum`

В текущей тестовой выгрузке `tp` нельзя автоматически называть
`tp6h`. Запрошены четыре отдельные временные точки, а не все
последовательные часы шестичасового интервала.

Внутреннее рабочее название:

`tp1h`

## Пропуски

`sst` содержит пропуски над сушей.

Маска валидных значений SST должна храниться отдельно и учитываться
при вычислении loss и метрик.

Остальные тестовые поля не содержат NaN.

## Правила

1. Файлы в Raw Data не изменять.
2. Не перезаписывать исходные NetCDF.
3. Не конвертировать исходные единицы внутри raw-файлов.
4. Обработанные данные сохранять только в Team Workspace.
5. CDS API-токены в хранилище не загружать.
6. Файл `.cdsapirc` никому не передавать.
