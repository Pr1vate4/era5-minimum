# День 1 — каркас и первый MVP

## Цель дня

Получить не презентацию и не сложную модель, а первый воспроизводимый вертикальный срез:

`данные → нормализация → ConvAE → latent → восстановление → метрики → таблица по размерам выборки`.

## Обязательный результат

- [x] единая гипотеза проекта;
- [x] репозиторная структура;
- [x] `AGENTS.md` для Codex;
- [x] синтетический ERA5-подобный датасет;
- [x] быстрый PCA baseline 32× и каркас ConvAE 32×/64×;
- [x] эксперимент по нескольким train sizes;
- [x] RMSE, MAE, latitude-weighted RMSE и метрики по каналам;
- [x] тесты;
- [ ] получить реальные ERA5/организаторские данные;
- [ ] согласовать точную официальную метрику и трактовку 32–64×.

## Критерий зачёта дня

На чистой машине выполняется:

```bash
pip install -e .
pytest -q
python -m era5_minimum.experiments --config configs/mvp.yaml
```

и появляется `outputs/mvp/summary.csv` с тремя экспериментами.
