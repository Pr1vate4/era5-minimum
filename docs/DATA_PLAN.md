# План работы с данными

## До выдачи организаторского датасета

1. Создать CDS-аккаунт и принять лицензию ERA5.
2. Скачать маленький raw sample через `scripts/download_era5_example.py`.
3. Проверить реальные имена координат, units, missing values и mask SST.
4. Не принимать решение по `tp6h` до подтверждения семантики организаторами.

## После выдачи данных

Первым коммитом сохранить только schema report:
- список файлов;
- размеры;
- variables и units;
- coordinates;
- временной диапазон и cadence;
- NaN/masks;
- min/max/mean/std;
- приблизительный размер одного временного среза.

Сырые данные в Git не добавлять.

## Рекомендуемый split

- train — ранний период;
- temporal gap — не менее одного характерного окна зависимости;
- validation — следующий фиксированный период;
- test — последний скрытый/фиксированный период.

Для хакатонного эксперимента exact boundaries определяются после просмотра временного диапазона.
