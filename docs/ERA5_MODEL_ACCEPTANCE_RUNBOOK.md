# Приёмка модели и кодека ERA5

Скрипт `scripts/model/accept_codec.py` проверяет уже обученную модель. Он не
обучает модель, не скачивает ERA5 и не изменяет Zarr-хранилища.

## Что требуется от контрольной точки модели

Контрольная точка должна содержать:

- `state_dict`, загружаемый строго в `ConvAutoencoder`;
- конфигурацию модели с 28 входными каналами;
- версию кодека и шаг квантования;
- точный канонический порядок 28 каналов;
- 28 train-only mean/std и SHA256 манифеста источника.

Порядок каналов:

```text
t2m, mslp, u10, v10, tp6h, sst, tcwv, tcc,
T1000, T925, T850, T700, U1000, U925, U850, U700,
V1000, V925, V850, V700, Z1000, Z925, Z850, Z700,
Q1000, Q925, Q850, Q700
```

Отсутствующая контрольная точка не заменяется случайными весами, synthetic
моделью или статистиками валидации: результат приёмки в таком случае
`BLOCKED`.

## Что проверяется

Для каждого кадра выполняется цепочка:

```text
физические поля → маска SST → нормализация только по train → кодировщик →
квантование → канонический поток Хаффмана → независимое декодирование →
декодер → обратная нормализация → метрики
```

SST над сушей остаётся `NaN` в физическом наборе; нулевое заполнение возможно
только на границе модели. Самостоятельный файл `.e5ac` содержит заголовок,
формы, checksum модели, порядок каналов, квантование и entropy payload.

Единственный публикуемый бинарный коэффициент сжатия:

```text
(32 × T × C × H × W) / (8 × полный_размер_битового_потока_в_байтах)
```

В полный размер входят заголовок и все данные на кадр. Уменьшение числа
элементов latent tensor не называется коэффициентом сжатия.

## Команды

Проверить команду без загрузки модели:

```bash
python scripts/model/accept_codec.py \
  --dataset-root data/era5_28ch_demo --split validation \
  --checkpoint checkpoints/era5_codec.ckpt \
  --output-dir outputs/model_acceptance/demo --timestamps all --dry-run
```

Тест на небольшом фрагменте:

```bash
python scripts/model/accept_codec.py \
  --dataset-root data/era5_28ch_demo --split validation \
  --checkpoint checkpoints/era5_codec.ckpt \
  --output-dir outputs/model_acceptance/crop-128 \
  --timestamp 2020-01-01T00:00:00.000000000 \
  --crop-height 128 --crop-width 128 --device cpu --deterministic
```

Фрагмент не является глобальной проверкой. Для полноценной приёмки нужны вся
сетка, реальная контрольная точка, сериализованный поток, exact roundtrip,
независимое декодирование и физические метрики.

## Артефакты и ограничения

Скрипт сохраняет отчёт приёмки, происхождение модели и данных, конфигурацию,
метрики по временным меткам, время/ресурсы, расчёт сжатия и проверки roundtrip.
Метрики считаются в физических единицах с весами `cos(latitude)`; SST — только
над океаном; NRMSE использует объявленное train-only стандартное отклонение.

Текущий N32 pilot подтверждает техническую работу кодека, но не доказывает
прохождение полного ТЗ. Актуальный перечень незавершённых научных проверок
находится в [RESEARCH_STATUS.md](RESEARCH_STATUS.md).
